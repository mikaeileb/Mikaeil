# شروع تازه | Start Fresh

اپلیکیشن بومی اندروید برای مطالعه، عادت‌سازی، کتاب‌خوانی، پس‌انداز و مرور روزانه.

**شعار:** هر روز، یک قدم به نسخه بهتر خودت نزدیک‌تر شو.

## وضعیت نسخه
نسخه 1.1.0 با Kotlin، Jetpack Compose و Room ساخته شده است. رابط کاربری فارسی و راست‌چین است و در حالت آفلاین کار می‌کند. داده‌ها در پایگاه‌داده محلی دستگاه ذخیره می‌شوند.

## امکانات پیاده‌سازی‌شده
- داشبورد با خلاصه مطالعه، کتاب‌خوانی، عادت‌ها و پس‌انداز
- ثبت جلسه مطالعه به‌صورت تایمر آزاد یا پومودورو ۲۵ دقیقه‌ای، ورود دستی، هدف روزانه قابل تنظیم، هدف هفتگی/ماهانه پیشنهادی و تاریخچه
- کتابخانه شخصی، ثبت کتاب، هدف روزانه صفحات، ثبت صفحات مطالعه‌شده، درصد پیشرفت و تجمیع ثبت روزانه برای جلوگیری از امتیاز تکراری
- ساخت، ویرایش و حذف عادت با تأیید، ثبت روزانه با دکمه واضح، هدف و واحد هفتگی، زنجیره استمرار و سابقه فعالیت
- تعریف چند هدف پس‌انداز، ثبت واریز و برداشت، درآمد و هزینه دستی به تومان
- تقویم روزانه شمسی، گزارش‌های هفتگی و نمودار واقعی مطالعه
- دفتر روزانه و مرور عملکرد
- ماموریت‌های روزانه، XP و نشان‌های قابل بازشدن بر اساس ثبت‌های واقعی
- تم روشن و تاریک، یادآوری روزانه قابل تنظیم
- جست‌وجوی اطلاعات ثبت‌شده، خروجی/بازیابی پشتیبان JSON و خروجی گزارش CSV
- آیکون واقعی Adaptive Launcher با نسخه گرد و نسخه سازگار با لانچرهای قدیمی

## فناوری
- Kotlin 2.0.21
- Jetpack Compose + Material 3
- Room 2.6.1
- WorkManager برای یادآوری زمان‌بندی‌شده
- Gradle 8.9، Android Gradle Plugin 8.7.3، JDK 17
- حداقل Android 8.0 (API 26)

## ساخت APK با GitHub Actions
1. در مخزن GitHub به زبانه Actions برو.
2. گردش‌کار Build Start Fresh Android APK را انتخاب کن.
3. اجرای موفق را باز کن و Artifact با نام StartFresh-Android-APK را دریافت کن.
4. ZIP را باز کن و app-debug.apk را روی گوشی نصب کن.
5. در اولین نصب، برای اعلان‌ها مجوز لازم است؛ این مجوز اختیاری است.

هر Push شامل تغییرات پوشه StartFresh/ نیز گردش‌کار ساخت APK را اجرا می‌کند.

## ساخت محلی با Android Studio
پوشه StartFresh را در Android Studio باز کن. از Gradle با نسخه 8.9 و JDK 17 استفاده کن، SDK پلتفرم Android 35 و Build Tools 35.0.0 را نصب کن و سپس Task زیر را اجرا کن:

app > Tasks > build > assembleDebug

خروجی در مسیر زیر ساخته می‌شود:

StartFresh/app/build/outputs/apk/debug/app-debug.apk

## حریم خصوصی و محدودیت‌ها
- داده‌ها به حساب یا سرور ارسال نمی‌شوند و به‌صورت محلی نگهداری می‌شوند.
- درآمد، هزینه و پس‌انداز با ورود دستی ثبت می‌شوند و برنامه به بانک متصل نیست.
- اعلان‌ها به اجازه سیستم‌عامل وابسته‌اند و ممکن است با محدودیت باتری سازنده گوشی جابه‌جا شوند.
- فایل CSV خروجی شامل جلسه‌های مطالعه، ثبت کتاب‌خوانی و تراکنش‌های مالی است.

این نسخه هسته قابل استفاده را فراهم می‌کند، اما تمام جزئیات فهرست توسعه نهایی هنوز پیاده‌سازی نشده‌اند. موارد باقی‌مانده شامل جلد تصویری و نقل‌قول‌های کتاب، تاریخ شروع/پایان و یادداشت تفصیلی کتاب، روزهای فعال و یادآور مستقل برای هر عادت، تنظیم زمان‌های استراحت پومودورو، ویرایش کامل همه انواع رکوردها، تقویم ماهانه شبکه‌ای، چالش‌های ۷ و ۳۰ روزه، گزارش سالانه، PDF و راهنمای درون‌برنامه‌ای است.
