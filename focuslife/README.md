# FocusLife Android
اپلیکیشن فارسی برای تمرکز و مطالعه، مدیریت سرمایه، عادت‌ها، سلامت و اهداف.
- تایمر پومودورو و ثبت جلسه‌های یادگیری
- مدیریت تراکنش‌ها و شش صندوق شخصی با تومان
- پیگیری عادت‌ها و روند استمرار
- ثبت وزن، کالری و فعالیت ورزشی
- اهداف قابل پیگیری و درصد پیشرفت
- نمودارهای محلی، تقویم شمسی و پشتیبان‌گیری JSON
- ذخیره‌سازی محلی روی دستگاه؛ بدون نیاز به اینترنت برای عملکرد اصلی

برای ساخت با JDK 17، Android SDK 35 و Gradle 8.9:
`gradle assembleDebug`
فایل خروجی: `app/build/outputs/apk/debug/app-debug.apk`
